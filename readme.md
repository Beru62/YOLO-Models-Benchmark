# YOLO Models Benchmark ('PyTorch', 'TorchScript', 'ONNX', 'OpenVINO', 'TensorRT')

## Настройка окружения

Создание и активация виртуального окружения:

```powershell
python -m venv .venv
.venv\Scripts\activate
```

Установка PyTorch с поддержкой CUDA 13.2:

```powershell
# смотрите нужный под вашу конфигурацию индекс-url на сайте https://pytorch.org/get-started/locally/
# установите его первым, затем остальные зависимости из requirements.txt
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu132
```

Установка остальных зависимостей:

```powershell
python -m pip install --upgrade -r requirements.txt
```

## Форматы моделей

### 1. PyTorch (`.pt`)

Оригинальный формат модели PyTorch. Именно в нём хранятся веса обученной YOLO-модели.

**Как работает:** PyTorch загружает веса модели и выполняет вычисления на выбранном устройстве — CPU или CUDA (GPU).

**Особенности:**
- Родной формат для Ultralytics YOLO.
- Поддерживает CUDA и ускорение на GPU.
- Подходит для обучения, дообучения и инференса.
- Не требует предварительной конвертации.

### 2. TorchScript (`.torchscript`)

Сериализованное представление модели PyTorch, предназначенное для выполнения без исходного Python-кода модели.

**Как работает:** PyTorch преобразует модель в вычислительный граф, который можно сохранить и загрузить через TorchScript Runtime.

**Особенности:**
- Может работать без исходного Python-кода модели.
- Поддерживает CPU и CUDA.
- Подходит для развёртывания моделей в приложениях.
- Сохраняет совместимость с экосистемой PyTorch.

### 3. ONNX (`.onnx`)

Открытый формат представления нейронных сетей, позволяющий использовать модели в различных фреймворках и средах исполнения.

**Как работает:** модель PyTorch экспортируется в вычислительный граф ONNX. Затем этот граф выполняется через ONNX Runtime или другие совместимые движки.

**Особенности:**
- Не привязан к PyTorch.
- Поддерживает инференс на CPU и GPU.
- Может использовать CUDA Execution Provider.
- Может служить промежуточным форматом для TensorRT и OpenVINO.
- Удобен для переноса моделей между различными платформами.

### 4. OpenVINO (`.xml` + `.bin`)

Набор инструментов и среда исполнения от Intel для оптимизации и запуска нейронных сетей.

**Как работает:** модель преобразуется в формат OpenVINO IR (Intermediate Representation), состоящий из двух файлов:
- `.xml` — описание архитектуры модели и вычислительного графа.
- `.bin` — веса модели.

**Особенности:**
- Оптимизирован для процессоров Intel.
- Поддерживает CPU и совместимые ускорители Intel.
- Может эффективно работать на CPU без NVIDIA CUDA.
- Подходит для развёртывания моделей на устройствах Intel.

### 5. TensorRT (`.engine`)

Среда исполнения и оптимизации нейронных сетей, разработанная NVIDIA для высокопроизводительного инференса на GPU.

**Как работает:** модель преобразуется в оптимизированный TensorRT Engine. Во время сборки TensorRT анализирует вычислительный граф, подбирает оптимальные CUDA-ядра, выполняет оптимизации и может использовать FP16 или INT8 для ускорения вычислений.

**Особенности:**
- Оптимизирован для видеокарт NVIDIA.
- Поддерживает GPU-ускорение через CUDA.
- Поддерживает FP32, FP16 и INT8 (в зависимости от модели и конфигурации).
- Выполняет оптимизацию вычислительного графа под конкретное оборудование.
- Может значительно ускорить инференс по сравнению с обычным PyTorch.
- Созданный `.engine` обычно привязан к совместимой конфигурации GPU, CUDA и TensorRT.
- Первая сборка Engine может занимать несколько минут.



## Сравнение форматов

| Формат | Основное назначение | Среда исполнения |
|---|---|---|
| PyTorch | Исходная модель | PyTorch |
| TorchScript | Сериализация модели PyTorch | PyTorch |
| ONNX | Совместимость между фреймворками | ONNX Runtime |
| OpenVINO | Оптимизированный инференс | OpenVINO Runtime |
|TensorRT |	Высокопроизводительный GPU-инференс |	TensorRT Runtime |

## Особенности Benchmark

В процессе Benchmark сравниваются не только форматы файлов, но и различные среды исполнения.

Поэтому скорость инференса зависит от всей комбинации:

**Формат модели + Среда исполнения + Оборудование**

Результаты Benchmark следует рассматривать как сравнение производительности конкретных связок, а не исключительно форматов моделей.

## Сборка TensorRT Engine

При первом экспорте TensorRT необходимо создать оптимизированный файл `.engine`.

- **Первый запуск:** TensorRT собирает Engine, подбирает и компилирует оптимизированные CUDA-ядра. Процесс может занять несколько минут.
- **Повторные запуски:** если файл `.engine` уже существует и соответствует текущей модели и настройкам, повторная сборка обычно не требуется.
- **Инференс:** готовый `.engine` загружается напрямую и позволяет выполнять значительно более быстрый инференс по сравнению с процессом сборки.
